# Demo walkthrough

Run the deliberate demo seed against an empty workspace. It creates Alex/Sam, Work/Home/Health, connected tasks, routines, references, locations, an outing and historical/future dates. It refuses to overwrite an existing workspace. There is no reset-data product button.

1. Open Today and review capacity, focus, note and essentials.
2. Capture an Inbox task, organize it and plan it for today.
3. Switch List/Board/Timeline; change status and keep dates intact.
4. Edit presentation notes/checklist, preview/download its real attachment, and run a timer.
5. Switch people, show independent plans and timers, and explicitly assign shared work.
6. Plan a day with older work, Someday and a selected routine.
7. Inspect plant recurrence and water-filter completion-relative behavior.
8. Open a reference and explicitly link or copy it to a chosen task.
9. Open Saturday errands, reorder stops, and show manual/provider fallback.
10. Review the day, move/copy tasks, and restore a task from Trash.
11. Create a full backup and demonstrate validation/confirmation before restoring.

Google checks need real API configuration; the UI does not invent live route/weather results. Review verification.md for actual external checks and remaining gaps before presenting.
